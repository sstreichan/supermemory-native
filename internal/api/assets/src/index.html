05 — endpoints

Local API

Every request this dashboard makes, plus a few for your own tooling. A daemon only reachable from this machine needs no key. Once it is reachable from elsewhere (reverse proxy, LAN, internet) every call carries SUPERMEMORY_API_KEY — this console asks for it once and keeps it in this browser.

Documents Add, list, and forget memories in the local store. ›
  1. Add a document
    Embeds the content and writes it to both the index and the vault.
    curl -X POST http://localhost:6767/v3/documents \
  -H "Content-Type: application/json" \
  -d '{"content":"supermemory is running locally!","containerTag":"default"}'
  2. List documents
    Paginated, sorted across every container tag.
    curl -X POST http://localhost:6767/v3/documents/documents \
  -H "Content-Type: application/json" \
  -d '{"page":1,"limit":100,"sort":"createdAt","order":"desc"}'
  3. Forget a memory
    Delete by id, or by content within a container tag.
    curl -X DELETE http://localhost:6767/v4/memories \
  -H "Content-Type: application/json" \
  -d '{"id":"<memory-id>","containerTag":"default"}'
Search & profile Semantic search and the derived profile of static and dynamic facts. ›
  1. Search
    Results carry a cosine similarity score. Use query or q.
    curl -X POST http://localhost:6767/v4/search \
  -H "Content-Type: application/json" \
  -d '{"q":"what is running locally?","containerTag":"default"}'
  2. Profile
    Static and dynamic facts for a container tag, plus search results.
    curl -X POST http://localhost:6767/v4/profile \
  -H "Content-Type: application/json" \
  -d '{"q":"favorite color","containerTag":"default"}'
Administration Vault sync, container tags, and daemon config. ›
  1. Sync the vault
    Bi-directional sync between the OKF vault directory and the index.
    curl -X POST http://localhost:6767/v3/sync -d '{}'
  2. Container tags
    Aggregated counters per container tag.
    curl http://localhost:6767/v3/container-tags/list
  3. Daemon config
    Returns the port this daemon is bound to.
    curl -X POST http://localhost:6767/v3/config -d '{}'
